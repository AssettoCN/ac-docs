**先说明一下：请在 KN5 所在的原始文件夹中打包它们，不要把它们移动到任何地方。**

如果你需要保护自己的模型不被修改或盗用，Custom Shaders Patch 现在可以对它们加密。加密后的模型只能在装有 Custom Shaders Patch 的 Assetto Corsa 中使用，或者（可选地）在 Content Manager 的 Custom Showroom 中使用。在原版 Assetto Corsa 中，模型会变成这样：

![解密失败的示例](https://i.imgur.com/iOrMALP.jpg)

加密同时适用于车辆和赛道。请仔细阅读以下列表，其中有一些重要事项：

# 有哪些限制？

- 👉 **未经许可，请勿加密 Kunos 或他人的内容，否则你加密的文件要么损坏、要么被解密。此外，CSP 可能会开始显示有关内容被盗的警告。** 👈
- 默认情况下，你的车辆无法在 Custom Showroom 中使用。
  - 如果希望它们能用，请告诉我，我会在下一次 Content Manager 更新中加入对你的加密方式的支持。
  - 请记住，这可能会让窃取你的模型变得更容易。
- 任何人仍然可以用某些工具拦截 GPU 数据，从而拿到带贴图的原始模型。
- 我绝非这方面的专家，其中很可能存在一些重大的失误，导致东西容易被解密。
- 确保你的车辆或赛道文件夹名中没有大写字符。
- 如果存在多个同名网格，整个机制将无法工作。
- 网格和贴图的名称不得超过 200 个字符。

# 如何保证安全？

- 不要分享你的加密器！如果有人想逆向工程，这几乎等同于把你所有的内容以解密状态发布出去。
- 如果你加密的车辆解包后看起来过于光滑，请确认网格没有被过度缩放。
- 如果你未经许可加密了他人的内容，他们可能会拿到针对你模型的解密器，并随意处置。
  - 如果围绕一个被盗 mod 发生争执，但原作本身只是个低成本的移植，以至于有可能并非被盗、而是车辆被单独移植纯属巧合，那么谁也得不到什么。

# 如何使用：

你的加密器由两部分组成：`kn5enc_….exe` 和 `kn5enc_…_acdchecksum.exe`：

- 如果只想保护模型，使用 `kn5enc_….exe`。
- 如果你的数据打包在 “data.acd” 中，想在保护模型的同时防止数据被更改，使用 `kn5enc_…_acdchecksum.exe`。
  - 该模式保护数据不被更改，但不会加密数据。人们仍能查看和复制它，但数据一旦被更改，模型就会停止工作。这有助于防止别人修改物理后，以自己的名义把车辆作为“修复版”或“调校版”重新发布。

加密模型的步骤：

- 选择一种模式。
- 运行对应的可执行文件。
  - 无需把它复制到车辆文件夹之类的位置。
- 它会弹出文件选择对话框，从中选择要加密的 KN5。
  - 让 KN5 保留在原来的车辆或赛道文件夹中。
- 加密完成后，原文件旁会出现一个新的 KN5，带 `_encrypted.kn5` 后缀。
  - 手动用新文件替换原文件。
  - 务必备份原始模型——模型无法解密还原！

## 更新日志

目前共有三个版本，最容易的区分方式是看 ZIP 的文件大小：

- v1（914 KB）：初始版本；
- v2（701 KB）：加密器自身的保护、对重型模型的支持大幅改善、若干警告、加密内容的安全性略有提升；
- v3（695 KB）：更好的警告，例如会实际显示出哪些网格重名。

如果你需要更新的版本，请联系我。

## 其他说明

首先，我想请你重新考虑是否加密模型。我认为 Assetto Corsa 整体上的开放性是件好事，例如，深入研究其他车辆的制作方式对我学习制作自己的车辆帮助巨大。而且，如果有人纯粹为个人使用而调校某辆车，本来也无可厚非。当然，也确实有一些人喜欢乱改模型并把它们当作自己的作品重新发布，而且出于某种奇怪的原因专盯某几类车。如果你的模型可能招来这类人，加密当然完全合理（不过，考虑到这类人几乎从不添加任何有价值的东西，直接无视他们就好）。

如果有人盗取了你的内容并擅自加密，我对此非常抱歉。你可以[联系我](https://acstuff.ru/app/#contacts)，我们一起想办法解决。如果实在无法达成协议，我会为你准备一个专用解密器，能使用那个特定人员的密钥工作，用于取回被修改的模型、解密模型以供公开重新发布，或直接发布人人可用的解密器。

在 Custom Showroom 中加入对你的加密方式的支持可能会让事情更容易受攻击——那会引入又一个基于 C# 的入口，可能更容易被逆向工程。不过，想让你的车辆在那里正常显示还有另一种办法：专门为 Content Manager 制作一个新模型。只需做一个未加密的新 KN5，并通过 `[LOD_HR]` 节添加到 `lods.ini`——Assetto Corsa 会完全忽略它，而 Content Manager 会将其用作默认模型。当然，既然它没有加密，就要让它没法在 AC 里正常使用：加上 MeshSmooth 让它细致到 AC 里无法流畅运行，或者干脆去掉整个内饰或车轮，或者把所有东西合并到一起，或者以上全部都用上。

你会发现加密后的模型占用的磁盘空间可能比原始文件还小：这是正常现象，因为加密器还会对贴图做无损压缩，以节省磁盘空间并加快加载速度。

对了，你也可以把 KN5 直接拖放到 EXE 上。我想让正文部分尽量简单，所以觉得最好还是不提这类选项。

感谢你读到这里！如果你想要获取自己的加密工具，请[联系我](https://acstuff.ru/app/#contacts)。
