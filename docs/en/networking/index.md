# Networking & Telemetry

Documentation for Assetto Corsa network protocols and telemetry.

Pages in this section are faithful translations of their sources — no information beyond the original text is added, and protocol identifiers (struct names, field names, constants) are preserved verbatim. Original source archives are kept in the repo under [`reference/`](https://github.com/AssettoCN/ac-docs/tree/main/reference) with a [source index](https://github.com/AssettoCN/ac-docs/blob/main/reference.md).
