# AC EVO 模组开发

欢迎使用 **Assetto Corsa EVO** 模组开发管线文档。

AC EVO 使用全新的编辑器（Editor）和 SDK，相比 AC1 有了质的飞跃。本板块涵盖了车辆制作、物理调校、音频制作和驾驶员动画的完整工作流。

## 内容概览

### 🚗 车辆模组

从 FBX 导出规范、骨骼结构、编辑器使用到最终的车辆配置。

- **[编辑器与 FBX 要求](/evo/car/)** — 编辑器工作区设置、FBX 导出规范、骨骼层级、材质系统
- **[物理系统](/evo/car/physics/)** — 车辆物理调校管线
- **[音频系统](/evo/car/audio/)** — FMod 音频制作管线

### 🧍 驾驶员动画

使用 Blender 制作驾驶员动画，导入编辑器。

- **[动画管线](/evo/driver/)** — Blender 场景设置、动画规范、导出与导入

## 注意事项

> AC EVO 目前处于 **Early Access** 阶段，模组工具可能随游戏更新而变化。Kunos Simulazioni 会尽力保持向后兼容性，但未来的游戏更新可能需要对模组资产进行维护。
