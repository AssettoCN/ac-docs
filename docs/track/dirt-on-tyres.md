自 **v0.1.25-preview27** 起，赛道现在可以设置自定义的轮胎泥土参数，供 Tyres FX 使用。草屑和泥土碎粒都绘制为两种颜色之间的渐变（这样我就能把法线、alpha 和渐变一起塞进一张 RGBA 纹理里）。

如果这些颜色与纹理的颜色相配，看起来会更好。另外，比方说你有一条雪地赛道：这种情况下，可以把泥土颜色设为白色。

区分草地与泥土表面时使用的是 `WAV` 参数。如果是 `grass.wav`，那它就是一块草！

### 语法

```ini
[DIRT]
DIRT_COLOR_A = 153, 136, 101, 0.004  ; 第一种泥土颜色
DIRT_COLOR_B = 81, 72, 56, 0.004     ; 第二种泥土颜色
GRASS_COLOR_A = 52, 80, 48, 0.006    ; 第一种草屑颜色
GRASS_COLOR_B = 42, 51, 34, 0.006    ; 第二种草屑颜色
DIRT_GAIN = 1.0                      ; 泥土的累积速度
DIRT_FADE_GAIN = 1.0                 ; 泥土的消退速度
GRASS_GAIN = 1.0                     ; 草屑的累积速度
GRASS_FADE_GAIN = 1.0                 ; 草屑的消退速度
```

`DIRT_FADE_GAIN` 和 `GRASS_FADE_GAIN` 的作用不会太大：当车辆回到赛道上时，计算泥土流失依据的是车辆自身的物理脏污程度。但当你从草地驶入泥土，或从泥土驶入草地时，这两个参数决定了另一类污渍消失得有多快。
