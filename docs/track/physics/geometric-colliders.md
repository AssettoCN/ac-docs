最初，AC 中赛道可用的碰撞体类型只有网格碰撞体，它适合赛道表面和墙体这类场合，但对于灯柱等其他类型的障碍物，效果可能不尽如人意。此外，举例来说，如果你有一片建筑或较薄的双面墙，把包含所有这些墙体的网格替换为盒形碰撞体，可能会带来性能和稳定性上的提升。

### 语法

```ini
; data/surfaces.ini:

[_EXTENSION]
COLLIDER_DEBUG = 1  ; 设为 1 时，碰撞体的轮廓将被高亮显示（此外，设置后还将提供碰撞体的
                    ; 实时重载功能）

; 胶囊碰撞体：类似圆柱，但两端带有半球，比圆柱更快；
; 适合灯柱
[COLLIDER_CAPSULE_...]
RADIUS = 0.5         ; 胶囊半径

; 位置和朝向可以这样定义：
LENGTH = 10          ; 胶囊长度，单位米
POSITION = X, Y, Z   ; 胶囊中心在世界坐标中的位置
DIRECTION = 0, 1, 0  ; 方向（此处为竖直方向）

; 或者这样定义：
FROM = X, Y, Z       ; 世界坐标中的起点
TO = X, Y, Z         ; 世界坐标中的终点

; 圆柱碰撞体：类似胶囊，但端盖为平面，稍微更接近真实圆柱
[COLLIDER_CYLINDER_...]
... ; 参数与胶囊相同

; 球形碰撞体：常规碰撞体中最快的选项
[COLLIDER_SPHERE_...]
POSITION = X, Y, Z   ; 世界坐标中的位置
RADIUS = 5           ; 半径，单位米

; 盒形碰撞体
[COLLIDER_BOX_...]
POSITION = X, Y, Z   ; 世界坐标中的位置
SIZE = 10, 1, 5      ; 尺寸（米）：宽度、高度、长度
DIRECTION = 0, 0, 1  ; 朝向向量
UP = 0, 1, 0         ; 朝上的向量（用于倾斜的盒子）

; 平面碰撞体：平面内侧的所有内容都会被推到外侧；或许
; 适用于底层地面？或者用于封锁不可进入的区域？
[COLLIDER_PLANE_...]
POSITION = X, Y, Z   ; 平面位置
NORMAL = 0, 1, 0     ; 平面法线
```

此外，每个碰撞体还可以拥有以下属性：

```ini
[COLLIDER_SPHERE_...]
NAME = my_collider   ; 名称；供自定义碰撞参数的碰撞体过滤器使用
LAYER = 255          ; 碰撞体层
COLOR = R, G, B, A   ; 调试模式下轮廓显示的颜色
```

有关碰撞参数的更多信息请见[这里](/track/physics/collision-parameters)。至于层，同一层的碰撞体会被分为一组：CSP 在检查车辆与碰撞体的相交时，会先检查车辆与碰撞体组之间的相交，因此把位置相近的碰撞体归入单独的层可能是个好主意。不过也不必过于纠结：我希望将来能加入某种机制，让 CSP 自动把碰撞体分组为最优的组。

注意：你可以使用新的 Render Stats 应用中的 “Other threads” 按钮，查看物理部分执行碰撞检测步骤所花费的时间。
