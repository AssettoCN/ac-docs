> 译注：area map 译作「区域图」，指 CSP 在摄像机周围生成的赛道高度、表面颜色与遮挡快照  

为了实现一些额外效果，CSP 会在摄像机周围对赛道拍摄一张快照，记录赛道高度、表面颜色和遮挡信息。借助这些信息，可以做到：

- 让粒子与赛道表面、墙体及其他几何体发生碰撞；
- 让刹车痕和静态轮胎痕精确贴合赛道表面，即使物理表面对齐得没那么准也没问题；
- 确保尘土粒子和刹车痕的颜色与下方表面一致；
- 在隧道内绘制刹车痕时把遮挡考虑在内；
- 同样让动态（Lua 驱动的）赛道线沿表面对齐；
- 以及更多。

要显式配置这些贴图，可添加：

```ini
[AREA_HEIGHT_MAP]
GEOMETRY_MATERIALS=…
GEOMETRY_MESHES=…
COLOR_MATERIALS=…
COLOR_MESHES=…
```

`GEOMETRY_…` 用于高度图和遮挡的采样，`COLOR_…` 用于为烟雾、粒子和刹车痕着色，因此一般建议把草、泥土、沙地之类放进 `COLOR`，把车辆可能位于其上方的其他所有网格放进 `GEOMETRY`。例如，不要把路缘放进 `COLOR`，否则路缘上可能会冒出红色烟雾（不过 CSP 会额外做一步颜色过滤以防万一）。

默认情况下，CSP 将反射光几何体用作 `GEOMETRY`，将草地和水坑用作 `COLOR`，通常都能正常工作。只需确保反射光几何体配置正确；另外，除非你的赛道极其简单，请不要直接使用 `SURFACE_MATERIALS=?`。

自 0.3.0-preview331 起，Objects Inspector 上提供了一个工具，可用于校验这些贴图。
