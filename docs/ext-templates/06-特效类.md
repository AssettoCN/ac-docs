# 06. 特效类

## INCLUDE公共库引用

```ini
[INCLUDE] ; CSP 特效相关公共库
INCLUDE = common/gt3_exhaust_glow.ini ; GT3 排气管高温发红

INCLUDE = common/gt3_tyres_kunos.ini ; GT3 / Kunos 轮胎物理特效
INCLUDE = common/tyre_patterns.ini ; 轮胎花纹 / 胎面外观
```

## ① 特效类 EXT 主要内容

::: tip 🌟
参考 CSP 官方仓库说明：[`acc-extension-config`](https://github.com/ac-custom-shaders-patch/acc-extension-config)   
可用于车辆配置、赛道灯光、公共材质、灯光模板、VAO、Weather FX 等内容；  
大部分配置都通过 `.ini` 文件实现，并且很多车辆 / 赛道配置可以在游戏中实时生效。
:::

---

**特效类 EXT 主要处理车辆视觉效果：**

> 比如反射修复、透明层级、火焰、烟雾、火花、热浪、颗粒、雨滴、轮胎水雾、发光漫射等。

---

**主要内容：**

> Extra FX 标志
> 
> Particles FX 粒子特效
> 
> Exhaust Flames 排气火焰
> 
> Smoke / Dust / Rain Spray 烟雾与水雾
> 
> Sparks 火花
> 
> Heat Shimmer 热浪
> 
> Rain / Drops 雨滴与水痕
> 
> Bounced Lights 反弹光
> 
> Extra FX Emissive 发光漫射

## ③ Extra FX配置

::: tip 🥃
参考页面：[Ereebay / acc-extension-config Wiki「通用 – Extra FX 标志」](https://github.com/Ereebay/acc-extension-config/wiki/%E9%80%9A%E7%94%A8-%E2%80%93-Extra-FX-%E6%A0%87%E5%BF%97)  
`[EXTRA_FX]` 主要用于修复 Extra FX 下的透明件、玻璃、屏幕、HUD、运动模糊、TAA 拖影、Grass FX 透明异常等问题。
:::

**作用**

> 用于修复 Extra FX 下的透明件、玻璃、屏幕、HUD、运动模糊、TAA 拖影、Grass FX 草地透明等问题。

**常见用途：**

> 修复灯罩玻璃反射异常
> 
> 修复仪表玻璃 / HUD 拖影
> 
> 修复数字屏幕 TAA 残影
> 
> 修复快速旋转物体运动模糊错误
> 
> 修复草地在水面或反射表面前透明异常
> 
> 修复透明贴花 / 风挡横幅层级问题

---

### 基础样板

```ini
[EXTRA_FX] ; Extra FX 配置
DELAYED_RENDER = mesh_hud_display; 延迟渲染 HUD / 弹出仪表
SKIP_GBUFFER = mesh_gauge_clear_glass; 跳过透明件 G-buffer
MASK_GBUFFER = mesh_headlight_glass_l; 灯罩玻璃遮罩
BLEND_GBUFFER = mesh_windscreen_banner; 风挡横幅 / 透明贴花混合
ROTATING_FILTER = mesh_fan_blade; 快速旋转物体过滤
MOVING_FILTER = mesh_gauge_arrow_* ; 独立移动物体过滤
GLASS_FILTER = mesh_digital_screen; 屏幕 / 玻璃快速响应
FORCE_GRASSFX_GBUFFER_PASS = 1 ; 强制 Grass FX 进入 G-buffer pass
AUTOFIX = 1 ; 启用自动修复
```

---

### 常用组合样板

**车辆灯罩修复**

```ini
[EXTRA_FX] ; 灯罩 Extra FX 修复
MASK_GBUFFER = mesh_headlight_glass_l, mesh_headlight_glass_r ; 灯罩遮罩
AUTOFIX = 1 ; 启用自动修复
```

**HUD / 弹出仪表修复**

```ini
[EXTRA_FX] ; HUD / 弹出仪表修复
DELAYED_RENDER = mesh_hud_display, mesh_popup_gauge ; 延迟渲染 HUD / 弹出仪表
GLASS_FILTER = mesh_hud_glass ; HUD 玻璃快速响应
```

**数字屏幕拖影修复**

```ini
[EXTRA_FX] ; 数字屏幕拖影修复
GLASS_FILTER = mesh_digital_cluster, mesh_navigation_screen ; 屏幕快速响应
MOVING_FILTER = mesh_gauge_arrow_* ; 仪表指针移动过滤
```

**仪表小玻璃修复**

```ini
[EXTRA_FX] ; 仪表玻璃修复
SKIP_GBUFFER = mesh_gauge_clear_glass ; 极透明仪表玻璃跳过 G-buffer
GLASS_FILTER = mesh_gauge_clear_glass ; 仪表玻璃快速响应
```

**旋转风扇修复**

```ini
[EXTRA_FX] ; 旋转风扇修复
ROTATING_FILTER = mesh_cooling_fan, mesh_fan_blade_* ; 快速旋转件过滤
```

## ④ 刹车盘特效

::: tip 💿
CSP 官方车辆配置文档[`ks_lamborghini_gallardo_sl.ini`](https://github.com/ac-custom-shaders-patch/acc-extension-config/blob/master/config/cars/kunos/ks_lamborghini_gallardo_sl.ini?utm_source=chatgpt.com)和 Kunos 车辆配置里都有 `[BRAKEDISC_FX]`、`[BRAKEDISC_FX_FRONT]`、`[BRAKEDISC_FX_REAR]` 示例  
主要来调整刹车盘高温发光、反射、刻痕、陶瓷外观、内外半径等效果。
:::

> **正常启用该特效，刹车片mesh需要赋予`ksBrakeDisc`着色器**

### 基础样板

```ini
[BRAKEDISC_FX] ; 刹车盘特效
ACTIVE = 1 ; 启用刹车盘特效
CERAMIC = 1 ; 使用陶瓷刹车盘外观
CARVED = 1 ; 启用径向刻痕
CARVED_FREQUENCY = 15 ; 刻痕密度
GLOW_OFFSET = 1.3 ; 发光位置偏移
DEBUG = 0 ; 关闭调试模式

DISC_RADIUS = 0.21 ; 刹车盘外半径
DISC_INTERNAL_RADIUS = 0.115 ; 刹车盘内半径
RIM_HEIGHT = 0.15 ; 刹车盘边缘高度

AMBIENT_MULT = 1.0 ; 环境光强度
REFLECTION_MULT = 16 ; 反射强度
SIMPLIFY_NORMALS_K = 0.8 ; 法线简化强度
DISC_INTERNAL_RADIUS_SHARPNESS = 250 ; 内圈边缘锐度

WEAR_FORCE = 0.5 ; 磨损强度
NORMAL_MASK = 0, 0 ; 法线遮罩
LUMINOCITY_MASK = 0, 0 ; 发光遮罩
OVERRIDE_DIFFUSE_MAP = 0 ; 不覆盖漫反射贴图
OVERRIDE_NORMAL_MAP = 0 ; 不覆盖法线贴图
```

### 前后盘分开写

```ini
[BRAKEDISC_FX_FRONT] ; 前刹车盘特效
DISC_INTERNAL_RADIUS = 0.115 ; 前盘内半径
GLOW_OFFSET = 1.2 ; 前盘发光偏移

[BRAKEDISC_FX_REAR] ; 后刹车盘特效
DISC_INTERNAL_RADIUS = 0.105 ; 后盘内半径
GLOW_OFFSET = 1.1 ; 后盘发光偏移
```

### 自定义刹车盘发光贴图

```ini
[BRAKEDISC_FX] ; 自定义刹车盘发光
ACTIVE = 1 ; 启用
CERAMIC = 0 ; 普通钢盘
CARVED = 1 ; 启用刻痕
NORMAL_MASK = disc_normal.dds, 1 ; 自定义法线贴图
LUMINOCITY_MASK = disc_glow.dds, 1 ; 自定义发光遮罩
OVERRIDE_NORMAL_MAP = 1 ; 覆盖法线
OVERRIDE_DIFFUSE_MAP = 0 ; 不覆盖漫反射
GLOW_OFFSET = 1.2 ; 发光偏移
WEAR_FORCE = 0.5 ; 磨损强度
```

---

### 调整建议

> 刹车盘太亮 → 降低 `REFLECTION_MULT `/ `AMBIENT_MULT`
> 
> 刹车盘不发红 → 检查 `ACTIVE `和 `GLOW_OFFSET`
> 
> 刻痕太密 → 降低 `CARVED_FREQUENCY`
> 
> 盘面形状不准 → 调 `DISC_RADIUS `/ `DISC_INTERNAL_RADIUS`
> 
> 陶瓷盘效果不需要 → `CERAMIC = 0`

## ⑤ 轮胎物理特效

::: tip 💿
 CSP 官方车辆配置文档[`_doc_config_cars.ini`](https://github.com/ac-custom-shaders-patch/acc-extension-config/blob/master/_doc_config_cars.ini?utm_source=chatgpt.com)  
列出了 `[TYRES_FX]` 的损伤、颗粒磨损、平斑、胎体形变、高光衰减、法线变化等参数；  
Kunos 车辆配置里也有 `TYRES_FX` 示例。
:::

**作用**

> 控制轮胎平斑、颗粒磨损、胎面损伤、轮胎变形和受力视觉变化。

### 基础样板

```ini
[TYRES_FX] ; 轮胎物理特效
DAMAGE_DEBUG = 0 ; 调试模式，1 为初始显示损伤

; 磨损 / 平斑 / 颗粒
DAMAGE_FLAT_GAIN = 200.0 ; 平斑损伤强度
DAMAGE_FLAT_FADE = 0.1 ; 平斑消退速度
DAMAGE_GRAIN_GAIN = 1.0 ; 颗粒磨损强度
DAMAGE_GRAIN_MAX = 0.4 ; 最大颗粒磨损
DAMAGE_WIDTH_K = 0.95 ; 损伤宽度
DAMAGE_OFFSET_K = 0.0 ; 损伤位置偏移

; 损伤区域材质表现
DAMAGE_SPEC_MULT = 0.6 ; 损伤区域高光强度
DAMAGE_SPEC_EXP_MULT = 0.2 ; 损伤区域高光指数
DAMAGE_REFL_MULT = 0.4 ; 损伤区域反射强度
DAMAGE_OCCLUSION_MULT = 0.8 ; 损伤区域 AO 强度
DAMAGE_NORMALS_MULT = 2.0 ; 损伤区域法线强度

; 胎体形变
FLEX_SKEW_SMOOTHING = 0.1 ; 胎体形变响应速度
FLEX_MAX_SKEW_MULT = 0.8 ; 最大偏斜倍率
FLEX_PROFILE_MULT = 0.6 ; 胎面形变倍率
FLEX_SKEW_RANGE_MULT = 2.0 ; 形变影响范围
FLEX_MULT = 1.0 ; 整体形变强度
```

### 更明显的赛道胎磨损

```ini
[TYRES_FX] ; 强化轮胎磨损表现
DAMAGE_FLAT_GAIN = 250.0 ; 锁胎平斑更明显
DAMAGE_FLAT_FADE = 0.08 ; 平斑消退更慢
DAMAGE_GRAIN_GAIN = 1.2 ; 颗粒磨损更明显
DAMAGE_GRAIN_MAX = 0.45 ; 最大颗粒磨损提高
DAMAGE_WIDTH_K = 0.92 ; 损伤区域更集中
DAMAGE_NORMALS_MULT = 2.0 ; 增强损伤法线
FLEX_MULT = 1.0 ; 保持正常胎体形变
```

---

### 调整建议
> 轮胎平斑不明显 → 提高 `DAMAGE_FLAT_GAIN`
> 
> 平斑消失太快 → 降低 `DAMAGE_FLAT_FADE`
> 
> 颗粒感不明显 → 提高 `DAMAGE_GRAIN_GAIN`
> 
> 轮胎损伤太宽 → 降低 `DAMAGE_WIDTH_K`
> 
> 轮胎形变太夸张 → 降低 `FLEX_MULT`
> 
> 胎体太硬 → 提高 `FLEX_PROFILE_MULT `/ `FLEX_MAX_SKEW_MULT`

---

## ⑥ 排气火焰特效

::: tip ♨️
CSP 的火焰效果属于 Particles FX 的一部分，官方 `particles_fx.ini` 里有 `[FLAMES]` 全局模块；  
玩家和车辆配置常用 `[EXHAUST_FLAMES]` 控制单车排气火焰，例如松油门回火、限速器喷火、平踩换挡火焰和防迟滞火焰。
:::

### 普通弱火样板

```ini
[EXHAUST_FLAMES] ; 普通弱火排气火焰
DISCHARGE = 1 ; 启用松油门回火
DISCHARGE_CHARGE_TIME = 0.5 ; 需要一定蓄力
DISCHARGE_DELAY = 0.15 ; 回火延迟
DISCHARGE_DURATION = 0.25 ; 火焰较短
DISCHARGE_PROBABILITY = 0.25 ; 低概率触发
DISCHARGE_INTENSITY = 1.0 ; 较弱火焰

LIMITER = 1 ; 启用断油火焰
LIMITER_INTENSITY = 0.8 ; 弱断油火焰
FLAT_SHIFT = 0 ; 关闭换挡火焰
ANTILAG = 0 ; 关闭防迟滞火焰
```

### 强化火焰样板

```ini
[EXHAUST_FLAMES] ; 排气火焰系统

; 防迟滞火焰
ANTILAG = 1 ; 启用防迟滞火焰
ANTILAG_DELAY = 0.01 ; 防迟滞触发延迟
ANTILAG_INTENSITY = 5 ; 防迟滞火焰强度
ANTILAG_INTERVAL_MIN = 0.35 ; 最小喷射间隔
ANTILAG_INTERVAL_MAX = 0.45 ; 最大喷射间隔
ANTILAG_TURBO_THRESHOLD = 0.01 ; 涡轮压力触发阈值

; 发动机损伤火焰
DAMAGE = 0 ; 关闭损伤火焰
DAMAGE_DURATION = 0.0 ; 损伤火焰持续时间
DAMAGE_INTENSITY = 0 ; 损伤火焰强度
DAMAGE_PROBABILITY = 0 ; 损伤火焰概率

; 松油门回火
DISCHARGE = 1 ; 启用松油门喷火
DISCHARGE_CHARGE_TIME = 0.01 ; 油门蓄力时间
DISCHARGE_DELAY = 0.01 ; 松油门后延迟
DISCHARGE_DURATION = 0.5 ; 喷火持续时间
DISCHARGE_PROBABILITY = 1 ; 喷火概率
DISCHARGE_INTENSITY = 5 ; 喷火强度
DISCHARGE_RPM_THRESHOLD_MIN = 6400 ; 最低触发转速
DISCHARGE_RPM_THRESHOLD_MAX = 7000 ; 最高触发转速
DISCHARGE_WATER_TEMPERATURE_THRESHOLD = 65 ; 水温达到后才触发

; 平踩换挡火焰
FLAT_SHIFT = 1 ; 启用升档喷火
FLAT_SHIFT_COOLDOWN = 0.01 ; 换挡冷却时间
FLAT_SHIFT_DURATION = 0.5 ; 喷火持续时间
FLAT_SHIFT_GAS_THRESHOLD = 10 ; 油门阈值
FLAT_SHIFT_INTENSITY = 5 ; 喷火强度
FLAT_SHIFT_PROBABILITY = 1 ; 喷火概率
FLAT_SHIFT_RPM_THRESHOLD = 2000 ; 转速阈值

; 限速器火焰
LIMITER = 1 ; 启用断油喷火
LIMITER_DELAY = 0.01 ; 喷火延迟
LIMITER_INTENSITY = 5 ; 喷火强度
LIMITER_RPM_THRESHOLD = 1000 ; 最低触发转速
```

### 排气烟雾 + 火焰组合

```ini
[PARTICLES_FX_EXHAUST_0] ; 排气烟雾
POSITION = 0.45, 0.35, -2.1 ; 排气位置
DIRECTION = 0, 0, -1 ; 喷出方向
COLOR = 0.45, 0.45, 0.45, 0.5 ; 烟雾颜色
LIFE = 1.2 ; 持续时间
SIZE = 0.12 ; 粒子大小
INTENSITY = 0.6 ; 烟雾强度
SPEED = 0.8 ; 喷出速度
SPREAD = 0.25 ; 扩散范围

[EXHAUST_FLAMES] ; 排气火焰
DISCHARGE = 1 ; 松油门回火
DISCHARGE_PROBABILITY = 0.5 ; 回火概率
DISCHARGE_INTENSITY = 2 ; 回火强度
LIMITER = 1 ; 断油喷火
LIMITER_INTENSITY = 1.5 ; 断油火焰强度
```

###  排气热浪

```ini
[PARTICLES_FX_EXHAUST_HEAT_0] ; 排气热浪
POSITION = 0.45, 0.35, -2.1 ; 热浪位置
DIRECTION = 0, 0, -1 ; 热浪方向
INTENSITY = 0.5 ; 热浪强度
SIZE = 0.25 ; 热浪范围
LIFE = 0.8 ; 持续时间
```

---

### 调整建议

> 想更炸 → 提高 `DISCHARGE_INTENSITY `/ `DISCHARGE_PROBABILITY`
> 
> 想少喷 → 降低 `DISCHARGE_PROBABILITY`
> 
> 想高转才喷 → 提高 `DISCHARGE_RPM_THRESHOLD_MIN`
> 
> 冷车不喷 → 提高 `DISCHARGE_WATER_TEMPERATURE_THRESHOLD`
> 
> 换挡没火 → 检查 `FLAT_SHIFT`
> 
> 断油没火 → 检查 `LIMITER`
> 
> 防迟滞没火 → 检查 `ANTILAG_TURBO_THRESHOLD`

## ⑦ 排气管高温变红

::: tip ⭕
官方 Kunos 车辆配置里有 [`common/gt3_exhaust_glow.ini`](https://github.com/ac-custom-shaders-patch/acc-extension-config/blob/master/config/cars/common/gt3_exhaust_glow.ini?utm_source=chatgpt.com) 的使用示例，例如保时捷 GT3 R 配置中通过 `ExhaustPoint`、`ExhaustMeshes_MultiMap`、`ExhaustGlowTint` 等参数做排气管高温发红；  
玩家社区也经常把 exhaust glow、exhaust smoke、flames 作为车辆 EXT 特色效果。
:::

### 官方模板写法

```ini
[INCLUDE: common/gt3_exhaust_glow.ini] ; 引入官方 GT3 排气发红模板

ExhaustPoint = 0.0, 0.20, -2.10 ; 排气发热点位置
ExhaustLightPoint = 0.0, 0.20, -2.30 ; 排气发光点位置
ExhaustMeshes_MultiMap = mesh_exhaust_glow ; 需要发红的排气 Mesh
ExhaustRadiusInner = 0.02 ; 内圈半径
ExhaustRadiusThicknessInv = 12 ; 发红厚度控制
ExhaustGlowTint = 0.02 ; 发红色调强度
ExhaustNormalsK = 0.1 ; 法线影响
ExhaustAreaScale = 0.1, 1, 0.03 ; 发红区域缩放
ExhaustMirror = 0 ; 是否镜像
ExhaustLightRange = 0.5 ; 发光范围
```

### 简化自定义发光写法

```ini
[EMISSIVE_...] ; 排气管高温发红
INPUT = WATER_TEMPERATURE ; 绑定水温，也可改成 RPM / SPEED
INPUT_MIN = 1 ; 输入最小值
INPUT_MAX = 100 ; 输入最大值
INPUT_LUT = (|84=0|95=1|) ; 84 以下不红，95 开始变红
USE_SMOOTH_TRANSITION = 1 ; 平滑过渡
MESHES = mesh_exhaust_pipe_01, mesh_exhaust_pipe_02 ; 需要发红的排气 Mesh
COLOR = 555, 20, 0, 3 ; 高温红橙色
AFFECTS_TRACK = 1 ; 影响地面光照
SPECULAR_MULT = 3 ; 高光反射强度
```

### 用转速控制发红

```ini
[EMISSIVE_...] ; 转速控制排气发红
INPUT = RPM ; 绑定发动机转速
INPUT_MIN = 0 ; 最低转速
INPUT_MAX = 8000 ; 最高转速
INPUT_LUT = (|4000=0|6500=1|8000=1|) ; 高转后逐渐变红
USE_SMOOTH_TRANSITION = 1 ; 平滑变色
MESHES = mesh_exhaust_pipe ; 排气管 Mesh
COLOR = 555, 20, 0, 2.5 ; 红橙色发光
SPECULAR_MULT = 3 ; 高光强度
```

---

### 调整建议

> 发红太早 → 提高 `INPUT_LUT `触发值
> 
> 发红太晚 → 降低 `INPUT_LUT `触发值
> 
> 颜色太亮 → 降低 `COLOR `最后一位
> 
> 红色太假 → 降低 `COLOR `第一位或加一点橙色
> 
> 只想排气口红 → 缩小 Mesh 或使用官方 `ExhaustAreaScale`

## ⑧ 引擎盖形变

**作用**

> 让引擎盖、前盖、薄板件有轻微鼓包、震动、形变效果。

### 样板代码

```ini
[DEFORMING_HOOD] ; 引擎盖形变效果
NAME = mesh_hood_panel ; 需要形变的父节点或 Mesh

OFFSET_Y_MIDDLE = 0.28 ; 中部 Y 方向偏移
OFFSET_Y_END = 0.01 ; 末端 Y 方向偏移
OFFSET_Z_END = 0.12 ; 末端 Z 方向偏移

BULGING_EXTRA = 0.5 ; 额外鼓包强度
BULGING_EXPONENT = 4.0 ; 鼓包曲线，越大越集中

NOISE_Y_AMPLITUDE = -0.86 ; Y 方向噪波幅度
NOISE_Z_AMPLITUDE = -0.4 ; Z 方向噪波幅度
NOISE_Y_FREQENCY = 8.0 ; Y 方向噪波频率，按官方拼写保留
NOISE_Z_FREQENCY = 7.0 ; Z 方向噪波频率，按官方拼写保留

Z_FACTOR = 2.5 ; Z 方向形变倍率
Z_BIAS = 0.15 ; Z 方向偏移基准
```

### 温和形变样板

```ini
[DEFORMING_HOOD] ; 温和引擎盖形变
```

> 
> 高速空气压力鼓包
> 
> 赛车前盖震动
> 
> 碳纤维薄板抖动

## ⑪ Particles FX 粒子特效

::: tip 🌰
参考官方 [`particles_fx.ini`](https://github.com/ac-custom-shaders-patch/acc-extension-config/blob/master/config/particles_fx.ini?utm_source=chatgpt.com) 包含软粒子、火花、火焰、热浪、碎屑等模块。
控制烟雾、火焰、火花、碎屑、热浪等粒子效果。
:::

### 参考样板

```ini
[BASIC] ; Particles FX 总开关
ENABLED = 1 ; 启用 Particles FX

[AC_PARTICLES] ; 原生粒子增强
SOFT_PARTICLES = 1 ; 软粒子
SORTED_PARTICLES = 0 ; 粒子排序
SHADOWED_PARTICLES = 0 ; 粒子阴影
REWORKED_HEAT_SHIMMER = 1 ; 新热浪效果

[SPARKS] ; 摩擦火花
ENABLED = 1 ; 启用火花
LIMIT = 40000 ; 火花上限

[FLAMES] ; 新火焰
ENABLED = 1 ; 启用火焰
DEBUG_MODE = 0 ; 关闭调试颜色
USE_DYNAMIC_SHADOWS = 1 ; 火焰动态阴影
LIMIT = 2000 ; 火焰上限
```

**注意：**

> 这些多是 CSP 全局设置。
> 
> 文档里一般只作为参考，不建议随便写进车辆 EXT。
