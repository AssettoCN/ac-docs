# 04. 模拟仪表类

::: tip ⚽
参考 CSP 官方 [Wiki「Cars – Instruments inputs」](https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Cars-%E2%80%93-Instruments-inputs)
该页面说明 CSP 的仪表输入系统，可把车辆状态数据绑定到模拟仪表、数字仪表、动画和发光对象中；本章节整理其中的**模拟仪表输入**部分，用于控制速度表、转速表、油量表、水温表、涡轮表、G 力表等指针式或机械式仪表。
:::

## ① 常用模拟仪表样板

### 转速表

```ini
[ANALOG_INDICATOR_RPM] ; 转速表
INPUT = RPM ; 绑定发动机转速
INPUT_MIN = 0 ; 最低转速
INPUT_MAX = 8000 ; 最高转速
INPUT_LAG_UP = 0.85 ; 转速上升平滑
INPUT_LAG_DOWN = 0.85 ; 转速下降平滑
```

**适用：**

> 机械转速表
> 
> 赛车转速表
> 
> 仪表盘 RPM 指针

#### 转速表警告发光

**作用**

> 当转速超过指定数值时，让转速表警告区域发光或闪烁。
> 
> 适合高转提示、换挡提示、红区警告灯。

```ini
[EMISSIVE_RPM_WARNING] ; 转速表警告发光
INPUT = RPM ; 绑定发动机转速
INPUT_THRESHOLD = 7000 ; 超过 7000 转触发
NAME = mesh_rpm_warning_light ; 绑定转速警告 Mesh
COLOR = 500, 0, 0, 0.2 ; 触发后红色警告光
OFF_COLOR = 1, 1, 1, 0.1 ; 未触发时弱白光
FALLBACK_HEADLIGHTS_COLOR = 10, 10, 10, 5 ; 车灯开启时备用颜色
CAST_LIGHT = 0 ; 不投射实际光线
TOGGLE_VISIBILITY = 1 ; 启用可见性切换
TOGGLE_VISIBILITY_INVERSE = 0 ; 不反向显示
BLINKING_PATTERN = (|0=2|1=0|2=2|3=0|4=2|5=0|6=2|7=0|8=2|9=0|10=2|11=0|12=2|13=0|14=2|15=0|16=2|) ; 闪烁节奏
BLINKING_DURATION = 2 ; 闪烁周期
```

## ② 多值输入选择方法

::: tip ⚽
有些输入是一组数据，例如四个轮胎、四个车身高度、四个悬挂行程。  
 这类输入需要配合 `INPUT_SELECTOR`。
:::

---

### 常用选择

> INPUT_SELECTOR = X / FIRST   ; 第 1 个值
> 
> INPUT_SELECTOR = Y / SECOND  ; 第 2 个值
> 
> INPUT_SELECTOR = Z / THIRD   ; 第 3 个值
> 
> INPUT_SELECTOR = W / FOURTH  ; 第 4 个值
> 
> INPUT_SELECTOR = MIN         ; 最小值
> 
> INPUT_SELECTOR = MAX         ; 最大值
> 
> INPUT_SELECTOR = AVG         ; 平均值
> 
> INPUT_SELECTOR = SUM         ; 求和
> 
> INPUT_SELECTOR = LEN         ; 总长度

---

### 胎压表

```ini
[ANALOG_INDICATOR_TYRE_PRESSURE_FL] ; 左前胎压表
INPUT = TYRE_PRESSURE ; 绑定胎压
INPUT_SELECTOR = X ; 左前轮
INPUT_MIN = 10 ; 最低胎压
INPUT_MAX = 40 ; 最高胎压
INPUT_LAG_UP = 0.9 ; 胎压上升平滑
INPUT_LAG_DOWN = 0.9 ; 胎压下降平滑
```

四轮对应：

> X = 左前
> 
> Y = 右前
> 
> Z = 左后
> 
> W = 右后

## ④ 输入修正参数

### 倍率和偏移

```ini
[ANALOG_INDICATOR_SPEED_MPH] ; 英里速度表
INPUT = SPEED ; 绑定车速
INPUT_MULT = 0.621371 ; km/h 转 mph
INPUT_MIN = 0 ; 最低速度
INPUT_MAX = 200 ; 最高速度
```

---

### LUT 映射


### Debug 排错

> 指针不动
> 
> → 检查 INPUT 是否写对
> 
> 指针范围不对
> 
> → 检查 INPUT_MIN / INPUT_MAX
> 
> 指针抖动
> 
> → 增加 INPUT_LAG_UP / INPUT_LAG_DOWN
> 
> 指针方向不对
> 
> → 检查仪表动画角度设置
> 
> 数值太大或太小
> 
> → 使用 INPUT_MULT / INPUT_ADD 修正
> 
> 表盘刻度不均匀
> 
> → 使用 INPUT_LUT
> 
> 四轮数据不对
> 
> → 检查 INPUT_SELECTOR
> 
> 测试时不好判断
> 
> → 使用 INPUT_DEBUG 固定数值

## 推荐写法规则

> 速度表 → INPUT = SPEED
> 
> 转速表 → INPUT = RPM
> 
> 油量表 → INPUT = FUEL
> 
> 水温表 → INPUT = WATER_TEMPERATURE
> 
> 油温表 → INPUT = OIL_TEMPERATURE
> 
> 油压表 → INPUT = OIL_PRESSURE
> 
> 涡轮表 → INPUT = TURBO
> 
> G 力表 → INPUT = G_FORCE + INPUT_SELECTOR = LEN
> 
> 胎压表 → INPUT = TYRE_PRESSURE + INPUT_SELECTOR
> 
> 轮胎温度表 → INPUT = TYRE_TEMPERATURE + INPUT_SELECTOR
> 
> 指针太跳 → 加 INPUT_LAG_UP / INPUT_LAG_DOWN
> 
> 数值范围不准 → 调 INPUT_MIN / INPUT_MAX
> 
> 单位不对 → 用 INPUT_MULT
> 
> 表盘刻度不均匀 → 用 INPUT_LUT
> 
> 测试指针 → 用 INPUT_DEBUG
