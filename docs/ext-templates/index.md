# 常用 Ext 配置模板

本章节系统整理 CSP（Custom Shaders Patch）Extension 配置的常用模板，覆盖从基础语法到各类视觉/物理效果的完整写法。每个章节聚焦一类配置场景，包含 section 说明、参数列表与可直接复制的实战示例。

::: tip 📌 来源
本章节内容镜像自飞书知识库「神力科莎知识库 / 常用 Ext 配置模板」系列，图片已本地化，可离线阅读。
:::

## 阅读建议

- **新手**：先读 [Ext 基础](./01-Ext基础)，了解加载路径与 Section 抽象结构。
- **想做车漆/玻璃**：直接看 [材质类](./02-材质类)，每个模板都带游戏内效果截图与可复制 ini。
- **想点亮车灯**：[灯光类](./03-灯光类) 涵盖了从基础 EMISSIVE 到 CustomEmissiveMulti 的高级用法。
- **调试不生效**：参考 [Ext 基础 / 调试流程](./01-Ext基础#调试流程)，按"对象匹配 → 配置覆盖 → CSP 版本"顺序排查。
