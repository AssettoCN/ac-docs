## ③ CustomEmissive灯光

::: tip ⚽
CustomEmissive 主要负责灯组本体按状态发光，原生 LIGHT 主要负责实际照亮环境；  
现代 LED、分区灯组和复杂车灯优先用 CustomEmissive，更好控制和维护。
:::

### 前灯

**作用**

> 控制前灯发光
> 
> 可同时生成前灯照明
> 
> 适合近光灯、远光灯、日行灯主发光

`Headlights` 模板会生成 `EMISSIVE_HEADLIGHTS_...`，并可生成 `LIGHT_HEADLIGHT_0` 照明；  
官方模板里包含 `ACT_AS_HEADLIGHTS`、`LAG`、`LOCATION = FRONT` 等输出。

**前灯发光 + 照明**

```ini
[CustomEmissive] ; 前灯发光模板
Meshes = mesh_headlight_l, mesh_headlight_r ; 作用左右前灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 前灯发光区域
@ = Headlights, Channel = 0, Intensity = 1.0, Color = "20, 20, 20", Direction = "0, 0, 1", Offset = "0, 0, 0" ; 绑定前灯
```

---

### 刹车灯

**作用**

> 踩刹车时点亮
> 
> 适合尾灯刹车区、高位刹车灯、贯穿式刹车灯

`BrakingLights` 输出 `EMISSIVE_BRAKE_...`，默认颜色来自 `DefaultBrakingColor`，并支持 `HeadlightsIntensity` 作为小灯状态下的低亮度尾灯回退颜色。

```ini
[CustomEmissive] ; 刹车灯发光模板
Meshes = mesh_brake_light_l, mesh_brake_light_r ; 作用刹车灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 刹车灯发光区域
@ = BrakingLights, Channel = 0, Intensity = 1.0, Color = "40, 0, 0" ; 绑定刹车灯
```

---

###  倒车灯

**作用**

> 挂倒挡时点亮
> 
> 可生成倒车照明
> 
> 适合白色倒车灯、后部照明

`ReverseLights 会生成 EMISSIVE_REVERSE_...，并可生成 LIGHT_REVERSE_0，默认位置为后部。`

```ini
[CustomEmissive] ; 倒车灯发光模板
Meshes = mesh_reverse_light_l, mesh_reverse_light_r ; 作用倒车灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 倒车灯区域
@ = ReverseLights, Channel = 0, Intensity = 1.0, Color = "40, 40, 40", Direction = "0, 0, -1", Offset = "0, 0, 0" ; 绑定倒车灯
```

### 转向灯

**作用**

> 控制左右转向灯
> 
> 适合前转向灯、后转向灯、侧转向灯、动态流水转向基础发光

官方模板包含 `TurningLightsFront`、`TurningLightsRear`、`TurningLightsFrontCorner`、`TurningLightsRearCorner`、`TurningLightsRearCombined`、`DashTurningLights` 等 Mixin；转向灯默认输出左右两组 `EMISSIVE_TURNSIGNAL_LEFT/RIGHT` 和对应 `LIGHT_TURNSIGNAL`。

**前转向灯**

```ini
[CustomEmissive] ; 前转向灯模板
Meshes = mesh_indicator_front_l, mesh_indicator_front_r ; 作用前转向灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 发光区域
@ = TurningLightsFront, Channel = 0, Intensity = 1.0, Color = "25, 12, 0" ; 绑定前转向灯
```

**后转向灯**

```ini
Meshes = mesh_indicator_front_l, mesh_indicator_front_r ; 作用前转向灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 发光区域
@ = TurningLightsFront, Channel = 0, Intensity = 1.0, Color = "25, 12, 0" ; 绑定前转向灯
```

**角灯转向灯**

```ini
[CustomEmissive] ; 前角灯转向模板
Meshes = mesh_indicator_corner_l, mesh_indicator_corner_r ; 作用角灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 发光区域
@ = TurningLightsFrontCorner, Channel = 0, Intensity = 1.0, Color = "25, 12, 0" ; 绑定前角灯转向
```

**尾灯转向与刹车共用区域**

```ini
[CustomEmissive] ; 后转向刹车共用模板
Meshes = mesh_rear_combined_light_l, mesh_rear_combined_light_r ; 作用共用灯组 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 共用发光区域
@ = TurningLightsRearCombined, Channel = 0, Intensity = 1.0, Color = "25, 12, 0" ; 后转向与刹车共用
```


### 牌照灯

**作用**

> 车灯开启时照亮牌照
> 
> 适合牌照灯发光、后牌照区域补光

```ini
[CustomEmissive] ; 牌照灯发光模板
Meshes = mesh_license_plate_light ; 作用牌照灯 Mesh
Resolution = 512, 512 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 512, 512 ; 发光区域
@ = LicensePlateLights, Channel = 0, Intensity = 1.0, Color = "10, 10, 10" ; 绑定牌照灯
```

**牌照补光：**

```ini
[LIGHT_EXTRA_LICENSE_PLATE] ; 牌照区域补光
BOUND_TO = mesh_license_plate_light ; 绑定牌照灯 Mesh
POSITION = 0, 0.45, -2.1 ; 灯光位置
DIRECTION = 0, -0.3, -1 ; 灯光方向
COLOR = 1, 0.95, 0.85, 3 ; 暖白灯光颜色与强度
RANGE = 1.2 ; 照明范围
SPOT = 120 ; 光锥角度
SPOT_SHARPNESS = 0.4 ; 光锥边缘锐度
AFFECTS_TRACK = 0 ; 不照亮赛道
EXTERIOR_ONLY = 1 ; 仅外部视角
```

### 雾灯

**作用**

> Extra A 控制的前 / 后雾灯
> 
> 适合前雾灯、后雾灯、赛车额外灯

官方 `FogLights` 同时生成发光和 `LIGHT_EXTRA_0FOGFRONT`；`FogLightsRear` 生成后雾灯发光和 `LIGHT_EXTRA_0FOGREAR`，默认参数包含 `SPOT`、`RANGE`、`AFFECTS_TRACK`、`FADE_AT` 等。

**前雾灯**

```ini
[CustomEmissive] ; 前雾灯模板
Meshes = mesh_fog_light_l, mesh_fog_light_r ; 作用前雾灯 Mesh

@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 发光区域
@ = FogLightsFront, Channel = 0, Intensity = 1.0, Color = "20, 20, 20", Position = "-0.55, 0.25, 1.8" ; 绑定前雾灯
```

**后雾灯**

```ini
[CustomEmissive] ; 后雾灯模板
Meshes = mesh_rear_fog_light_l, mesh_rear_fog_light_r ; 作用后雾灯 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率
@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 1024, 1024 ; 发光区域
@ = FogLightsRear, Channel = 0, Intensity = 1.0, Color = "20, 0, 0", Position = "-0.55, 0.45, -2.0", Mirror = 0.55 ; 绑定后雾灯
```

### 开门灯

**作用**

> 车门开启时点亮
> 
> 适合门板警示灯、脚窝灯、迎宾灯、车门底部投射灯

官方 `OpenDoorLight` 会生成 `EMISSIVE_OPENDOORS_...` 和 `LIGHT_OPENDOORS_0`，支持 `Position`、`Mirror`、`Direction` 等灯光参数。

```ini
[CustomEmissive] ; 开门灯发光模板

```

### 仪表指示灯

**作用**

> 按输入状态点亮仪表图标

官方还提供 `DashWarningABS`、`DashWarningTC`、`DashWarningEngine`、`DashWarningTemperature`、`DashWarningTyrePressure`、`DashWarningFuel` 等快捷 Mixin。

### 自定义仪表图标

**作用**

> 车辆没有仪表图标 Mesh 时，额外生成仪表图标  
> 适合补 ABS、TC、转向箭头、远光灯、油量灯等图标

官方 `CustomEmissiveExtra` 用于给缺少仪表图标的车创建新指示图标，通常从 `[CustomEmissiveExtra]` 开始，并添加 icon 或 arrow。

**图标样板**

```ini
[CustomEmissiveExtra] ; 额外仪表图标模板
Meshes = mesh_dashboard_panel ; 绑定仪表面板 Mesh
Brightness = 0.05 ; 图标基础亮度

@ = CustomEmissiveExtra_Icon, Role = HIGHBEAM, Position = 0.02, 0.01, 0.0, Size = 0.008, 0.008 ; 创建远光灯图标
@ = CustomEmissiveExtra_Icon, Role = ABS, Position = 0.04, 0.01, 0.0, Size = 0.008, 0.008 ; 创建 ABS 图标
@ = CustomEmissiveExtra_Icon, Role = TRACTIONCONTROL, Position = 0.06, 0.01, 0.0, Size = 0.008, 0.008 ; 创建 TC 图标
```

**转向箭头样板**

```ini
[CustomEmissiveExtra] ; 额外转向箭头模板
Meshes = mesh_dashboard_panel ; 绑定仪表面板 Mesh
Brightness = 0.05 ; 图标基础亮度

@ = CustomEmissiveExtra_TurnArrows, Position = 0.02, 0.02, 0.0, Gap = 0.02, SizeBase = 0.004, 0.004, SizeArrow = 0.00
```

### 多通道发光

**作用**

> 同一个 Mesh 内分多个发光区域
> 
> 适合同一灯组内同时存在刹车灯、转向灯、倒车灯、示宽灯

**样板代码：**

```ini
[CustomEmissiveMulti] ; 多通道发光模板
Meshes = mesh_rear_light_group ; 作用后灯组 Mesh
Resolution = 1024, 1024 ; 发光遮罩分辨率

@ = CustomEmissive_Rect, Channel = 0, Start = 0, 0, Size = 512, 512 ; 刹车灯区域
@ = BrakingLights, Channel = 0, Intensity = 1.0 ; 绑定刹车灯

@ = CustomEmissive_Rect, Channel = 2, Start = 0, 512, Size = 512, 512 ; 倒车灯区域
@ = ReverseLights, Channel = 2, Intensity = 1.0 ; 绑定倒车灯
```

## ④ 发光漫射 Emissive

**作用**

> 让发光物体周围也有一点泛光。
> 
> 适合屏幕、按钮、尾灯灯罩、阅读灯、氛围灯。

### 屏幕漫射样板

```ini
[EXTRA_FX_EMISSIVE_...] ; 屏幕发光漫射
MESHES = mesh_dashboard_screen ; 屏幕 Mesh
RANGE = 0.055 ; 漫射范围
COLOR = 0.95, 0.95, 1.05, 3 ; 漫射颜色与强度
DIRECTED = 1 ; 定向漫射
DISABLE_WITH_EMISSIVE_LIGHT = 0 ; 不与自发光互斥
INTERIOR_ONLY = 1 ; 仅内饰
EXTERIOR_ONLY = 0 ; 不限制外部
```

### 灯罩漫射样板

```ini
[EXTRA_FX_EMISSIVE_...] ; 灯罩发光漫射
MESHES = mesh_taillight_glass_l, mesh_taillight_glass_r ; 灯罩 Mesh
RANGE = 0.015 ; 漫射范围
COLOR = 200, 0, 0, 0.8 ; 红色漫射
DIRECTED = 0 ; 非定向漫射
DISABLE_WITH_EMISSIVE_LIGHT = 1 ; 与自发光灯互斥
INTERIOR_ONLY = 0 ; 不限制内饰
EXTERIOR_ONLY = 0 ; 不限制外部
```

**适用**

> 数字仪表屏幕  
> 中控屏  
> 尾灯灯罩  
> 发光按钮  
> 阅读灯  
> 氛围灯

## ⑤ 物理投光 SelfLight 

**作用**

> 给发光物体附近增加小范围补光
> 
> 适合头灯玻璃、尾灯灯罩、牌照灯、内饰小灯

`SelfLight` 模板输出为 `LIGHT_EXTRA_...`，官方模板默认包含 `COLOR`、`SPOT`、`RANGE`、`FADE_AT`、`FADE_SMOOTH`、`SPECULAR_MULT`、`EXTERIOR_ONLY`、`INTERIOR_ONLY` 等参数。

```ini
[SelfLight_...] ; 左前灯自发光补光
POSITION = -0.6, 0.45, 1.8 ; 灯光位置
DIRECTION = 0, 0, 1 ; 灯光方向
BOUND_TO = mesh_headlight_l ; 绑定左前灯 Mesh
COLOR = 1, 1, 1, 30 ; 灯光颜色与强度
SPOT = 190 ; 光锥角度
SPOT_SHARPNESS = 0.5 ; 光锥边缘锐度
RANGE = 0.5 ; 照明范围
SPECULAR_MULT = 1 ; 高光影响强度
SELF_LIGHTNING = 1 ; 启用自照明
EXTERIOR_ONLY = 1 ; 仅外部视角
INTERIOR_ONLY = 0 ; 不限内饰视角
DIFFUSE_CONCENTRATION = 0.9 ; 漫反射集中度
```

**左右对称写法：**

```ini
[SelfLight_...] ; 左右前灯自发光补光
POSITION = -0.6, 0.45, 1.8 ; 左灯位置
MIRROR = 0.6 ; 自动镜像右灯
DIRECTION = 0, 0, 1 ; 灯光方向
COLOR = 1, 1, 1, 30 ; 灯光颜色与强度
SPOT = 190 ; 光锥角度
RANGE = 0.5 ; 照明范围
BOUND_TO = mesh_headlight_l ; 绑定左灯 Mesh
```

## ⑦ 原生灯光 Section

::: tip ⚽
参考 CSP 官方 [Wiki「Cars – Emissive objects」](https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Cars-%E2%80%93-Emissive-objects) | [「Cars – Instruments inputs」](https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Cars-%E2%80%93-Instruments-inputs)  
该页面说明车辆发光对象 `EMISSIVE_*` 的配置写法，用于让指定 Mesh 根据车辆状态自动发光。  
例如普通车灯、刹车灯、倒车灯、左右转向灯、远近光灯、Extra 自定义灯、仪表指示灯、档位灯、开门提示灯等，并支持自定义输入、备用颜色、闪烁、流水转向、可见性切换和亮度延迟等功能，适合制作车辆灯组、仪表图标和状态灯
:::
