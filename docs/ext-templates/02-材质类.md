### 抬头引用模板
```ini
[INCLUDE] ; CSP 材质公共库引用
INCLUDE = common/materials_base.ini ; 基础材质公共库

INCLUDE = common/materials_toon.ini ; 卡通 / Toon 材质公共库
INCLUDE = common/dev_material_carpaint.ini ; 开发版车漆材质模板
INCLUDE = common/dev_material_interior.ini ; 开发版内饰材质模板
INCLUDE = common/custom_rims.ini ; 轮毂材质 / 轮毂外观模板
INCLUDE = common/human_surface_template.ini ; 人物 / 皮肤表面材质模板
INCLUDE = common/tyre_patterns.ini ; 轮胎花纹 / 胎面贴图模板
INCLUDE = common/displays.ini ; 引用屏幕形状生成库
```

---

### 车漆全局设置

```ini
[INCLUDE: common/materials_carpaint.ini] ; 引入车漆模板

CarPaintMaterial = body_paint ; 默认车漆材质名（可自定义）
CarPaintVersionAware = 4 ; 使用新版车漆默认参数
DisableDev = 1 ; 禁用旧开发材质覆盖
```

> CSP 官方 materials_carpaint.ini 中，
> 
> 默认会使用：
> 
> CarPaintMaterial=Carpaint ; 使用车漆 Shader
> 
> CarPaintVersionAware=1 ; 使用旧版默认参数
> 
> 将 CarPaintVersionAware 改为 4 后，会启用新版车漆默认参数,9999则为默认使用所有新特性

## 材质匹配方式

### 按材质匹配

```ini
MATERIALS = body_paint ; 普通 Section 写法，匹配指定材质
```

---

### 按 Mesh 限定

```ini
Meshes = mesh ; 匹配指定mesh
```

---

### 通配匹配

```ini
MATERIALS = glass* ; 匹配所有 glass 开头材质
MESHES = light_* ; 匹配所有 light_ 开头 Mesh
```

## ① 车漆材质

::: tip 🚗
CSP 官方车漆公共库包含 `Material_CarPaint_Solid`、`Metallic`、`Chrome`、`Pearl`、`Matte`、`Old`、`Chameleon`、`Metal`、`ChromaFlair`、`RainbowChrome`、`Rainbow` 等模板。  
官方文件中这些模板最后会输出为 `SHADER_REPLACEMENT`，并替换为 `smCarPaint`、`smCarPaint_old`、`smCarPaint_chameleon`、`smCarPaint_chromaFlair` 等 Shader。
:::

### 素色漆

**主要作用和表现：**

> 基础车漆
> 
> 无明显金属颗粒
> 
> 适合普通白色 / 红色 / 蓝色车身

**样板代码：**

```ini
[Material_CarPaint_Solid] ; 素色车漆模板
Materials = body_paint ; 作用车漆材质
BrightnessAdjustment = 0.85 ; 车漆整体亮度
ColoredSpecular = 0.4 ; 彩色高光强度
AmbientSpecular = 0.3 ; 环境高光强度
AmbientSpecularEXP = 2.0 ; 环境高光集中度
ClearCoatThickness = 0.04 ; 清漆层厚度
FresnelMax = 0.5 ; 边缘最大反射
FresnelC = 0.08 ; 正面基础反射
SpecularBase = 0.2, 100 ; 基础高光强度与锐度
```

**游戏内效果：**

![图片展示了一辆游戏内车辆的车漆材质效果。车辆外观为银灰色，车身线条流畅，车顶和引擎盖部分有明显的金属反射，车身中部有彩色高光，车尾处有金色高光。该图片对应文档中“金属漆”材质类的“游戏内效果”部分，直观呈现了金属漆增强金属反射、增加彩色高光、适合现代量产车车漆等主要作用和表现。](./images/02-材质类/01-FPzfbpL6.jpg)

### 哑光漆

**主要作用和表现：**

> 降低镜面反射
> 
> 扩散太阳高光
> 
> 适合磨砂漆 / 哑光膜

**样板代码：**

```ini
[Material_CarPaint_Matte]
MATERIALS = body_paint_matte                     ; 作用材质名
UseMetallicReflections = 0.2              ; 金属反射强度
FresnelEXP = 6                           ; 菲涅尔指数（边缘高光衰减）
FresnelMax = 0.6                         ; 菲涅尔最大值
FresnelC = 0.02                          ; 菲涅尔基础反射
FlakesK = 0.2                            ; 金属颗粒强度（0为关闭）
BrightnessAdjustment = 0.65              ; 整体亮度调整
ClearCoatSpecular = 1                    ; 清漆层高光强度
ClearCoatThickness = 0.65                ; 清漆层厚度
ClearCoatIOR = 1.10                      ; 清漆层折射率
ColoredSpecular = 1                      ; 高光带颜色
PearlescentSpecular = 1.5                ; 珠光高光强度
SpecularBase = 0.7, 25                   ; 基础高光（强度, 粗糙度）
SpecularSun = 0.0, 10000                 ; 太阳高光（强度, 指数）
AmbientSpecular = 0.5                    ; 环境高光强度
AmbientSpecularEXP = 2                   ; 环境高光指数
SecondaryReflection = 1                  ; 次级反射开关
PROP_... = detailUVMultiplier, 40        ; 细节贴图UV缩放倍数
PROP_... = isAdditive, 0                 ; 是否叠加模式（0关闭）
```

**游戏内效果：**

![图片展示了一辆黑色的车模，车身线条流畅，呈现出流线型设计。车模放置在灰色地面上，背景为深色。车模表面有明显的金属反射，车顶和车身侧面反射出周围环境的光线，车头部分反射出地面的纹理。该图片对应文档中“镀铬车漆”材质类介绍部分，直观呈现了镀铬车漆高反射、适合镀铬外观及镜面改装件的特点。](./images/02-材质类/05-EQTzbL4d.jpg)

### 旧漆 / 橘皮漆

**主要作用和表现：**

> 增加表面噪波
> 
> 制造橘皮漆面
> 
> 适合老车 / 旧车漆

**样板代码：**

```ini
[Material_CarPaint_Old] ; 旧车漆 / 橘皮车漆效果
Materials = body_paint_old ; 需要应用的车漆材质名称
FresnelMax = 0.9                    ; 菲涅尔最大反射强度，控制掠射角反光上限
FresnelC = 0.05                     ; 菲涅尔基础反射值，影响正面观察时反光强度
FlakesK = 0                         ; 金属颗粒强度，0为关闭金属漆颗粒效果
SpecularSun = 0.5, 1000            ; 阳光高光强度,高光锐度（数值越大高光越集中）
SpecularBase = 0.5, 200              ; 环境高光强度,高光锐度（影响非太阳光源反射）
AmbientSpecular = 0.1              ; 环境镜面反射强度
BrightnessAdjustment = 0.55           ; 亮度补偿，防止环境高光导致整体偏亮
ColoredSpecular = 0                ; 是否启用彩色高光，0为白色高光
AmbientSpecular = 0.1              ; 环境镜面反射强度
AmbientSpecularEXP = 2             ; 环境高光衰减指数，数值越大过渡越柔和
ClearCoatThickness = 0.2           ; 清漆层厚度，模拟表层透明保护漆
ClearCoatIOR = 1.25                ; 清漆层折射率，影响反射和折射效果
UseMetallicReflections = 0.2       ; 金属反射参与度，控制环境反射强度
SHADER = ksPerPixelMultiMap_NMDetail ; 支持细节法线的车漆着色器
PROP_... = detailNormalBlend, 0.17 ; 细节法线混合强度
PROP_... = detailUVMultiplier, 180 ; 细节法线平铺密度
RESOURCE_1 = txNormalDetail ; 细节法线资源槽
RESOURCE_FILE_1 = orangepeelNM.dds ; 橘皮法线贴图文件
```

**游戏内效果：**

![图片展示了一辆灰色的车模，车身线条流畅，车顶有明显的高光区域，表面有轻微的噪波效果，呈现出橘皮漆面的质感。该图片对应文档中“旧漆/橘皮漆”材质类的“游戏内效果”部分，直观呈现了该材质在游戏中的视觉效果，与上下文对增加表面噪波、制造橘皮漆面的描述相契合。](./images/02-材质类/07-IqPvbVam.jpg)

### 变色漆

**主要作用和表现：**

> 使用渐变贴图控制变色
> 
> 比 Chameleon 更适合复杂角度变色

**样板代码：**

```ini
[Material_CarPaint_ChromaFlair] ; ChromaFlair 变色车漆模板
Materials = body_paint_chromaflair ; 作用变色车漆材质
CarPaintVersionAware = 4 ; 使用新版车漆系统
GradientTexture = extension/textures/body/chromaflair_gradient.dds ; 变色渐变贴图
ChromaFlairFlakesBase = 0.5 ; 颗粒基础反射强度
ApplyTilingFix = 1 ; 启用平铺修正
ClearCoatReflectionSharpness = 1 ; 清漆反射清晰度
ColoredSpecular = 1 ; 彩色高光强度
PearlescentSpecular = 0 ; 关闭珠光高光
SpecularBase = 2, 20 ; 基础高光强度与锐度
UseDiffuseAlphaAsChromaFlairMask = 0 ; 不使用 Diffuse Alpha 遮罩
```

### 彩虹镀铬漆

**主要作用和表现：**

> 彩虹镀铬反射
> 
> 偏实验效果
> 
> 适合展示车 / 改装膜

**样板代码：**


## ⑤ 材质覆盖与着色器替换

::: tip ⚽
参考：[Ereebay / acc-extension-config Wiki《General – Shader replacements》。](https://github.com/Ereebay/acc-extension-config/wiki/%E9%80%9A%E7%94%A8-%E2%80%93-%E7%9D%80%E8%89%B2%E5%99%A8%E6%9B%BF%E6%8D%A2)  
主要说明`[SHADER_REPLACEMENT_...]` 用于修改已有材质的 Shader、参数、贴图、透明模式、阴影和显示距离。适合静态材质修改，例如车漆、玻璃、树叶、草地、发光材质、远景物体等
:::

### 基础模板

```ini
[SHADER_REPLACEMENT_...] ; 着色器替换配置
ACTIVE=1 ; 启用配置
SKINS=red? ; 限定 Skin 生效，仅车辆可用
MATERIALS=body_paint ; 匹配材质，可写 body_paint、glass*、texture:grass?.dds
MESHES=body_mesh ; 匹配 Mesh，可写 mesh_bush_?，通常用于限制作用范围
SHADER=ksPerPixelMultiMap ; 指定 Shader
SHADER_OVERRIDE_0=ksTree, ksGrass ; 原 Shader 为 ksTree 时改用 ksGrass
PROP_0=ksAmbient, 0.4 ; 环境光强度
PROP_1=ksDiffuse, 0.5 ; 漫反射强度
PROP_2=ksSpecularEXP, 120 ; 高光锐度
PROP_3=ksEmissive, 1,0,0 ; 自发光颜色
RESOURCE_0=txDiffuse ; 漫反射贴图槽
RESOURCE_FILE_0=body.dds ; 调用外部贴图，默认在配置文件旁边
RESOURCE_1=txNormal ; 法线贴图槽
RESOURCE_REF_1=txDetailNM ; 引用原材质其它贴图槽
RESOURCE_2=txMaps ; Maps 贴图槽
RESOURCE_COLOR_2=1,1,1 ; 创建纯色贴图
FILL_MISSING_TEXTURES=1 ; 自动补齐缺失贴图
FORCE_POINT_SAMPLER=1 ; 强制像素采样，适合小贴图保持锐利
BLEND_MODE=OPAQUE ; 混合模式，OPAQUE 不透明，ALPHA_BLEND 半透明，ADD 加法发光
CULL_MODE=FRONT ; 剔除模式，FRONT 单面显示，OFF 双面显示
DEPTH_MODE=NORMAL ; 深度模式，控制遮挡关系
CAST_SHADOWS=1 ; 投射阴影，TERRAIN 为低太阳角度投射
SEMITRANSPARENT_SHADOWS=TEXTURE ; 半透明阴影，按贴图计算
DOUBLE_FACE_SHADOW_BIASED=1 ; 双面偏移阴影，适合薄片模型
FIXED_EMISSIVE=1 ; 固定自发光亮度
IS_TRANSPARENT=1 ; 按透明物体排序渲染
LAYER=0 ; 渲染层级
LOD_IN=0 ; 开始显示距离，单位米
LOD_OUT=500 ; 结束显示距离，单位米
DISABLE_FAR_PLANE_CLIPPING=1 ; 禁用远平面裁切，适合远景物体
```

### 注意事项

> 静态材质修改优先用 SHADER_REPLACEMENT。  
> 修改材质属性优先用 MATERIALS，少用 MESHES，避免生成过多独立材质。  
> PROP 可以用 “...” 省略编号，但实际项目建议明确编号，方便检索。  
> RESOURCE 不建议用 “...”，避免贴图槽和值对应错误。  
> RESOURCE_FILE 默认读取配置文件旁边的贴图。  
> OPAQUE 和 ALPHA_TEST 性能较好，ALPHA_BLEND、ADD、MULTIPLY 更耗性能。  
> CULL_MODE=OFF 会双面渲染，适合薄片，但会增加性能消耗。  
> 删除 SHADER_REPLACEMENT 后，部分原始值不会自动恢复，需要重新加载内容。

### 自定义法线与颜色贴图

::: tip 🦦
参考：CSP 官方 `materials_interior.ini` 内的 PBR 材质模板写法。  
这个样板不限定皮革，也可以用于塑料、织物、地毯、金属、碳纤维等材质。

#### 自定义法线样板

```ini
DetailNormalBlend = -0.38 ; 细节法线混合强度，控制凹凸方向和明显程度
DetailNormalIntensity = 1.05 ; 法线整体强度，数值越高纹理越明显
ApplyTilingFix = 1 ; 开启平铺修正，减少重复纹理接缝
```

```ini
DetailNormalPBRSmoothnessGamma = 0.55 ; 细节粗糙变化，控制纹理区域的油润差异
ApplyTilingFix = 1 ; 开启平铺修正，减少重复纹理接缝
```

---

**写法规则与建议**

> Materials 必须填KN5里的真实材质名。
> 
> DetailNormalTexture 用来自定义细节法线。
> 
> DetailTexture 用来自定义颜色细节贴图。
> 
> DetailScale 同时影响细节法线和颜色贴图的平铺密度。
> 
> DetailNormalBlend 和 DetailNormalIntensity 一起控制法线强弱。
> 
> DetailNormalPBRSecondaryColor 只做色调微调，不是完整换色。
> 
> DetailNormalPBRReflectance 控制纹理区域的反射差异。
> 
> DetailNormalPBRSmoothnessGamma 控制纹理区域的粗糙和油润变化。
> 
> ApplyTilingFix 建议开启，可以减少平铺纹理接缝。

**生效条件**

> 需要调用 common/materials_interior.ini。
> 
> 建议使用 Material_Leather_v2、Material_Plastic_v2、Material_Fabric_v2 这类 \_v2 模板。
> 
> 如果不用 \_v2，需要确认该模板底层支持 DetailNormalTexture、DetailTexture 和 DetailNormalPBR 参数。
> 
> 贴图路径必须正确，文件需要放在CSP能读取的位置。
> 
> 材质名必须和KN5里的材质名一致。

### 车漆增加平铺细节法线

> 这个样板是在普通车漆参数基础上，额外接入一张可平铺的细节法线贴图，用来模拟橘皮漆、清漆层细小起伏和喷漆表面的轻微不平整。
> 
> 它不是新增一层材质，而是在车漆 shader 里使用 txNormalDetail 细节法线通道。

```ini
[Material_CarPaint_Old] ; 旧版车漆材质样板，适合橘皮漆和外观车漆
Materials = car_paint ; 需要套用的车漆材质名，必须和KN5里的材质名一致
FresnelMax = 0.9 ; 斜角反光强度，数值越大，侧面反光越强
FresnelC = 0.05 ; 正面基础反光，数值越大，正面也会更亮
FlakesK = 0 ; 金属颗粒强度，0为关闭金属漆颗粒
SpecularSun = 0.5, 1000 ; 太阳高光强度和锐度，第二个数越大，高光越集中
SpecularBase = 0.5, 200 ; 环境高光强度和锐度，影响普通环境下的反光
AmbientSpecular = 0.1 ; 环境反射强度，过高会让车漆发灰发亮
AmbientSpecularEXP = 2 ; 环境反射过渡，数值越大，反光变化越柔
BrightnessAdjustment = 0.45 ; 亮度补偿，数值越低整体越暗
ColoredSpecular = 0 ; 彩色高光开关，0为白色高光
ClearCoatThickness = 0.2 ; 清漆层厚度，用来模拟表面透明漆层
ClearCoatIOR = 1.25 ; 清漆层折射率，影响清漆反光质感
UseMetallicReflections = 0.2 ; 金属反射参与度，数值越大，环境反射越明显

SHADER = ksPerPixelMultiMap_NMDetail ; 使用支持细节法线的车漆着色器
PROP_0 = detailNormalBlend, 0.15 ; 细节法线强度，越高橘皮纹理越明显
PROP_1 = detailUVMultiplier, 180 ; 细节法线平铺密度，越高纹理越密
RESOURCE_0 = txNormalDetail ; 指定细节法线贴图槽
RESOURCE_FILE_0 = orangepeelNM.dds ; 平铺细节法线贴图文件
```

## ⑦ UV2

::: tip ⚽
参考原文：[Ereebay / acc-extension-config Wiki《General – UV2》。](https://github.com/Ereebay/acc-extension-config/wiki/%E9%80%9A%E7%94%A8-%E2%80%93-UV2)  
该页面说明 UV2 可通过额外 `.uv2` 文件加载，并可配合支持 UV2 的 Shader 使用贴纸贴图。
:::

UV2 用于给模型添加第二套 UV。

 主要作用是让贴纸、AO、细节贴图使用独立 UV，不占用原本车身贴图空间。

**适合：**

>  车身贴纸
> 
>  赛车号码
> 
>  赞助商 Logo
> 
>  独立 AO
> 
>  细节遮罩
> 
>  高精度局部贴图

---

### 文件放置

**`.uv2` 文件需要放在 KN5 文件旁边，并与 KN5 同名。**

> car.kn5 ; 原模型文件
> 
> car.uv2 ; UV2 数据文件

**赛道同理：**

> track.kn5 ; 原赛道模型
> 
> track.uv2 ; UV2 数据文件

---

### 支持 UV2 的 Shader

```ini
SHADER=nePerPixelMultiMap_AT_NMDetail_stickers ; 支持贴纸层的 MultiMap Shader
SHADER=smCarPaint ; CSP 车漆 Shader，支持贴纸相关参数
SHADER=stPerPixelMultiMap_specular ; 支持贴纸的赛道/物体 Shader
```

`smCarPaint` 推荐通过 `materials_carpaint.ini` 配置，主要使用：

```ini
StickersTexture=stickers.dds ; 贴纸颜色贴图
StickersMapsTexture=stickers_maps.dds ; 贴纸 Maps 贴图
StickersCoverDetails=1 ; 贴纸覆盖细节纹理
```

---

### 贴纸模式 extStickersMode

`extStickersMode` 用于控制贴纸层功能。  
 数值可相加使用。

```ini
PROP_0=extStickersMode, 1 ; 启用贴纸层
PROP_0=extStickersMode, 3 ; 启用贴纸层，并用贴纸 Alpha 隐藏细节纹理
PROP_0=extStickersMode, 7 ; 启用贴纸层、隐藏细节纹理，并启用贴纸 Maps
PROP_0=extStickersMode, 15 ; 启用贴纸层、细节遮盖、贴纸 Maps、贴纸法线
```

**数值含义：**

> 1 = 启用贴纸层
> 
> 2 = 贴纸 Alpha 同时影响漫反射 Alpha，用于隐藏细节纹理
> 
> 4 = 启用 txStickersMaps，影响 txMaps
> 
> 8 = 启用 txStickersNormals，影响 txNormal

**完整贴纸样板**

```ini
[SHADER_REPLACEMENT_...] ; UV2 贴纸完整配置
MATERIALS=body_paint ; 匹配车身材质
SHADER=nePerPixelMultiMap_AT_NMDetail_stickers ; 支持 UV2 贴纸的 Shader
PROP_0=extStickersMode, 15 ; 启用贴纸、细节遮盖、Maps、法线
RESOURCE_0=txStickers ; 贴纸颜色贴图槽
RESOURCE_FILE_0=stickers.dds ; 贴纸颜色贴图
RESOURCE_1=txStickersMaps ; 贴纸 Maps 贴图槽
RESOURCE_FILE_1=stickers_maps.dds ; 贴纸 Maps 贴图
RESOURCE_2=txStickersNormals ; 贴纸法线贴图槽
RESOURCE_FILE_2=stickers_n.dds ; 贴纸法线贴图
```

### Skin 独立 UV2
CSP 查找 UV2 补丁文件时，会优先检查皮肤文件夹。

因此可以给不同 Skin 使用不同 UV2。

> content/cars/car_name/skins/skin_name/car.uv2 ; 当前 Skin 专用 UV2
> 
> content/cars/car_name/car.uv2 ; 车辆通用 UV2

---

### 注意事项

> UV2 适合贴纸、Logo、号码牌等局部高精度内容。
> 
> .uv2 文件需要与 KN5 同名，并放在 KN5 旁边。
> 
> UV2 模型需要提前在 FBX 中准备第二套 UV。
> 
> 使用 UV2 前，需要确认当前 Shader 是否支持 UV2。
> 
> extStickersMode 的值可以相加，例如 1+2+4=7。
> 
> UV2 使用半精度，UV 超出 0–1 太多可能出现瑕疵。
> 
> 车辆 LOD 生成器支持 UV2，但部分模型可能需要额外调整。
