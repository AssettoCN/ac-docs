车身扭转是 v0.1.80-preview428 新增的特性（此前已加入过一段时间，但经过了修订），用于模拟车辆的扭转刚度（并进行可视化呈现）。使用时，在 `suspensions.ini` 中添加：

```ini
[_EXTENSION_FLEX]
TORSIONAL_STIFFNESS=10000  ; Nm/deg
TORSIONAL_DAMPING=100      ; Nm/(deg/s)
```

通过此方法，可以获得沿 Z 轴的扭转弯曲，足以应付大多数情况。实际的刚度值可以在网上查到。阻尼值的确定则更棘手一些，但应当有可能估算出来。

如果出于某些原因确实需要让车身沿其他轴扭转，或产生位置方向的挠曲，可以通过显式设置 CFM 和 ERP 值来实现，但我还没找到把 CFM 在各轴之间合理拆分的好办法，因此目前还相当粗糙。
