> 汉化时间：2026-09-11T23:30:00+08:00  

CSP 会尝试根据轮胎名称猜测某些设置，但遇到自定义轮胎名时，有时并不能如愿（由于这是一款竞速模拟游戏，后备轮胎类型永远是光头胎，这会让轮胎名称不合预期的车辆在雨天表现得格外滑）。

与其研究全部猜测规则并在名称上做文章，不如考虑在常规的 `NAME` 和 `SHORT_NAME` 旁边新增一个 `TYPE_HINT` 参数。部分类型还支持以 `TYPE_HINT_MODIFIER` 设置的可选修饰符。已知取值：

- `TREADED`：普通街道轮胎，擅长在积水或碎石路面行驶。
- `VINTAGE_PERFORMANCE`：老式运动轮胎。
- `RACING_TREADED`：能够排水的比赛轮胎，但不擅长碎石路面。
- `SLICK`：光头胎，在任何湿滑路面上都很糟糕。
- `SEMISLICK`：半光头胎，在湿滑路面上有些吃力。
- `RAIN`：真正的雨胎（若存在，CSP 就不会再生成雨胎）。
- `GRAVEL`：越野轮胎（0.2.4-preview1 新增）。
  - `TYPE_HINT_MODIFIER = RALLY1`：现代激进拉力轮胎。
- `ICE`：钉胎（0.2.5 新增）。
  - `TYPE_HINT_MODIFIER = RALLY`：更激进的钉子。
  - 其他可用参数：
    - `_SFX_ICE_FORCE_MULT_K` = 0.4：冰面上的基础抓地力乘数。
    - `_SFX_ICE_DAMP_MULT_K` = 1.4：雪地上的抓地力乘数。
    - `_SFX_ICE_BASE_SIZE` = 1400：每个车轮的负载阈值（单位 kg）。低于该阈值时，抓地力随重量成比例增加。
    - `_SFX_ICE_BASE_STIFF` = 0.0005：负载越过 base size 阈值后，抓地力停止增加的快慢程度。

注：`GRAVEL` 类型会为该会话激活 SurfacesFX。如果赛道没有显式设置表面类型，CSP 会根据表面参数猜测表面类型，并改变沙地物理的运作方式（在 0.2.8 之前，还会改变草地物理）。
