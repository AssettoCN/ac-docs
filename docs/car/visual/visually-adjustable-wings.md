此功能为车辆设置中不同的翼片角度添加视觉效果。并不复杂，只是一点旋转，与模拟仪表指针的工作方式非常相似。

### 语法

```ini
[ADJUSTABLE_WING_0]
NAME = WING_REAR  ; 要旋转的翼片根节点名称
WING = 2          ; aero.ini 中的节索引
ANGLE_BASE = 0    ; 角度的基础偏移
ANGLE_MULT = 0.8  ; 角度乘数
DEBUG_MODE = 0    ; 设为 1 可更轻松地调整枢轴
ROTATION_PIVOT = 0, 0.0, -0.035  ; 相对翼片根节点的旋转枢轴，应位于翼片网格中心
ROTATION_AXIS = -1, 0, 0         ; 我很确定大多数情况下不会更改此值，但以防万一
```

关于角度乘数，从逻辑上讲您当然可能想设为 1，但对于建模时没考虑此功能的现有车辆，我会将其稍微调低。至于调试模式，启用后翼片会来回摆动，而不再与空气动力学翼片联动：非常适合用来调整旋转枢轴。

### 猜测

补丁会尝试按以下条件寻找后翼：
- 节点名为 REAR_WING、WING_REAR、WING；
- 其枢轴高于 1.0 米且在 Z = -1.0 之后；
- 存在名为 REAR 的空气动力学翼片。

如果找到，它就会变为视觉可调节翼片，并使用一些温和的设置。如果您想禁用该行为，请手动添加任意一个可调节翼片。例如，如果完全不需要，可以这样：

```ini
[ADJUSTABLE_WING_0]
NAME = _non_existent_node_
```
