如果车辆有雨刷动画，还可以用它实现高速时雨刷的振动。

### 语法

```ini
[WIPERS]
WIND_THRESHOLDS_KMH = 60, 150  ; 雨刷开始振动的速度和达到最大振动的速度
WIND_AMPLITUDE_MULT = 1        ; 振幅乘数
WIND_FREQUENCY_MULT = 1        ; 频率乘数
WIND_OFFSET = 0.03             ; 振动所围绕的基础动画进度
```

之所以需要 `WIND_OFFSET`，是因为雨刷动画并不是从第一帧就开始移动，在前几帧晃动它往往完全看不到运动效果。该值添加了一段基础动画进度，雨刷围绕它晃动；随着速度从 0 增长到 `WIND_THRESHOLDS_KMH`，最终偏移也会逐渐从 0 增长到 `WIND_OFFSET`。

### 猜测

**语法**节中列出的设置即为所有车辆默认使用的设置。
