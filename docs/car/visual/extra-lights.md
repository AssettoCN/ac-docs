- 可以为 4 个额外按钮添加 LIGHT_EXTRA_1 到 ..._4，如下所示：

### 语法

```ini
[LIGHT_EXTRA_1]
; 可以使用
; POSITION=1,0,1
; 或者这样：
LINE_FROM=0.422, 0.1, -0.9
LINE_TO=0.422, 0.1, 0.9
BIND_TO_EXTRA_A=0
BOUND_TO=g_BODY_EXT_SUB6
BOUND_EMISSIVE_MAX=0.5
BIND_TO_HEADLIGHTS=0
BIND_TO_BRAKELIGHTS=0
COLOR=10
; 或者可以使用：
; COLOR_FROM = 0,1,0
; COLOR_TO = 1,0,0
EXTERIOR_ONLY=1
INTERIOR_ONLY=0
DIFFUSE_CONCENTRATION=0.9
DIRECTION=0, -1, 0
FADE_AT=40
FADE_SMOOTH=10
FADE_FAKE_SHADOW=0.8
LAG_OFF=0
LAG_ON=0
LAG=0.0
MIRROR=0.0
NOT_WITH_HEADLIGHTS=0
RANGE=0.9
RANGE_GRADIENT_OFFSET=0.3
SKIP_LIGHT_MAP=1
SPOT=210
SPOT_EDGE=0
SPOT_SHARPNESS=0.75
SPECULAR_MULT=0
SELF_LIGHTNING=1
VOLUMETRIC_LIGHT=0
```
