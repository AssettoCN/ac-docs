在处理 Python 应用时，原版 Assetto Corsa 对错误相当宽容：参数数量不正确或出现其他失败时都会被忽略。虽然这在某些情况下有帮助，但总体上可能让应用开发变得更困难——错误无法被正确上报。

因此，CSP 添加了可选的严格模式：在该模式下，错误会真正抛出给应用去处理。开发新应用时，我建议启用它。

要激活严格模式，只需在应用开头某处调用该函数：

```py
ac.ext_setStrictMode()
```
