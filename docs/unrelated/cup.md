# 这是怎么回事？

内容自动更新系统（CUP）是 Content Manager 的一项新功能，允许自动接收车辆、赛道和应用的更新通知与更新提议（稍后还会加入更多内容类型）。要使其工作，模组作者需要发布其内容最新版本的信息，以及获取更新的链接。

# 如果你是安装模组的一方

时不时地，对于某些模组，你可能会看到这样的东西：

<a href="https://i.imgur.com/4ivjaJG.png" target="_blank"><img src="https://i.imgur.com/4ivjaJG.png" width="400" /></a>

或者，如果发现了新版本，Content Manager 会在主菜单中通知你：

<a href="https://i.imgur.com/OeUcxSi.png" target="_blank"><img src="https://i.imgur.com/OeUcxSi.png" width="400" /></a>

点击那些带绿色箭头的按钮，它就会开始下载，或者打开一个网页，让你从那里获取更新（适用于付费模组之类）。即使 CM 会自动开始下载更新，你仍需要像往常一样在主菜单中同意安装。至少就目前而言，系统就是这样运作的。这些按钮还有上下文菜单：

<a href="https://i.imgur.com/8D4390f.png" target="_blank"><img src="https://i.imgur.com/8D4390f.png" width="400" /></a>

在这里，你可以跳过某个更新、彻底阻止某个模组更新，或者在链接失效或不含正确更新时，将该更新标记为损坏。请记住，模组作者注册新版本时会附上获取更新的 URL，而我们所有人都难免偶尔犯错，因此你可以用这个选项来让他们知道有什么地方不对劲。

# 如果你是制作模组的一方

请联系我，我会把你加入用于注册新更新的系统。这一切都做得很粗糙，但似乎能用。我不擅长做那些服务器端的东西。

一旦你进入了该系统，点击这里添加新条目：

<a href="https://i.imgur.com/xyBFMYV.png" target="_blank"><img src="https://i.imgur.com/xyBFMYV.png" width="400" /></a>

在弹出的窗口中，选择类型，并以小写形式输入 ID（也就是文件夹的名称）。注意：与所有其他内容不同，类型和 ID 以后无法更改。之后，点击 “Add new item”，添加完成后再填写其余详细信息：

<a href="https://i.imgur.com/Cw4liLT.png" target="_blank"><img src="https://i.imgur.com/Cw4liLT.png" width="400" /></a>

- **Name（名称）**：常规的可读名称，即其在 UI 中的显示方式；
- **Version（版本）**（必填）：你所发布内容的最新版本，采用应用可比较的常规格式（它会找出各个数字并逐个比较对应的数字）；
- **Update URL（更新 URL）**（必填）：用户按下带绿色箭头的更新按钮时打开的 URL。既可以是直接下载链接，也可以是包含更新的网页，适用于付费模组之类（更多说明见下方提示）；
- **Information URL（信息 URL）**：包含该内容相关细节的 URL；
- **Other IDs（其他 ID）**：如果你的更新包含不止一个内容（比如我们把 Peugeot 504 和 Peugeot 504 TN 放在同一个压缩包里发布），请在此处添加次要 ID（也就是各文件夹的名称），用逗号分隔；
- **Authors（作者）**、**changelog（更新日志）**：这里没什么特别之处，但请尽量简短，UI 里的空间不多。把所有额外的细节放到网页上，或者加一条备注，比如「详细更新日志请 [url="http://webpage/..."]点这里[/url]」（此处可以使用 BB 代码）；
- **Limited（受限）** 选项：开启它可将 URL 标记为非直接下载链接，适用于付费模组。开启后，按下更新按钮会在网页浏览器中打开该模组。否则，应用将直接开始下载；
- **Clean installation（干净安装）** 选项：开启后，会建议用户对新更新采用干净安装（这将成为默认选项）；
- 右上角的开关：关闭它可将该条目从注册表中完全隐藏。

### 非常重要的提示

如果你希望用户能够自动下载更新，我想请你选用 Content Manager 能够顺畅、可靠地进行下载的平台。以下是一些推荐的方式：

- Google Drive（免费 15 GB）：甚至支持首次下载在中途失败后从断点继续；
- Mega.nz（免费 15 GB）：与其他平台不同，它有正经的下载 API，因此应该是最可靠的；
- OneDrive（免费 5 GB）：目前似乎运作良好；
- Yandex.Disk（免费 10 GB）：请注意它在乌克兰被禁用，但除此之外，它工作得非常顺畅，有某种 API；
- Dropbox（免费 2 GB）：我想用它很容易触发配额限制，但除此之外，它几乎是完美的；
- MediaFire：目前似乎可用，但可能不太可靠；
- ShareMods：同样，能用，但随时可能出问题；
- 直链：当然，如果可行的话，这是最好的方式。

当然，也有一些托管 Assetto Corsa 模组的网站，但遗憾的是它们与 Content Manager 不兼容，因此如果重新上传不可行，最好将更新设置为以受限模式工作。但在这种情况下，我强烈建议重新上传更新。

### 其他提示

- 如果同一个压缩包里有多个车辆、赛道或应用，只为第一个创建条目，并把其余的放进 “Other IDs” 栏。当然，如果你有富余的时间，也可以分别建立条目，但不会有太多好处。
- Content Manager 会将更新信息缓存在 “%LOCALAPPDATA%\AcTools Content Manager\Temporary\CUP”（把该路径直接复制粘贴到 Windows 资源管理器即可找到正确的文件夹）中数小时。要检查更新是否生效，请删除该文件夹并重启应用。
- 用户名全部为小写，因为我不擅长在程序里处理那些东西。
